What do you want to create?
You can create courses, event, workshop on the subjects you teach. Students will be able to search the courses and request for a free trial class before enrollment.

You can create multiple courses on the same subject.
You can create/upload the study materials, notes, eBooks, Lectures, Exam preparation test papers, Exam suggestions.

The materials should be proprietary to the teacher and should be downloadable files (PDF, DOC, XL, JPEG, PNG, BMP etc.)
